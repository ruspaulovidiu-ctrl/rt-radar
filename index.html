Press Search. Without a backend, PubMed, Europe PMC, OpenAlex, Crossref, Semantic Scholar and ClinicalTrials.gov are searched live from this page; the other sources need the backend.

Backend connection

The page sends POST {API_BASE}/search with JSON {query, scope, scope_terms, composed_query, days, from_date, limit, sources, sites, languages}. The backend should AND the topic with the RT terms for each language in scope_terms (a ready-made English version is in composed_query); the page also hides any returned result lacking RT terms. sources lists API connectors (PubMed, OpenAlex, Semantic Scholar, Crossref, CORE, BASE, Mojeek, Exa…; every source tagged "via SearXNG" — Bing, DuckDuckGo, Startpage, Ecosia, Yahoo, MetaGer, Swisscows, Yep, Presearch, Google Scholar and the regional engines — is expected to be queried through a SearXNG instance with that engine enabled; sources tagged "paid", "key" or "subscription" need your own account); sites is a list of {id, domain} to search via site:domain queries through Brave/Google, since most European platforms have no public search API. It expects {"results":[...], "errors":{provider:message}} (errors optional). Result fields used: title, url, doi, source, source_type, language, published, updated, snippet, provider|providers.
